# Upgrade roadmap

These documents are implementation plans, not current product capability. Version
0.2.0 remains sequential and Codex-backed. Physics Auditor v1 is the first proposed
milestone; provider-neutral adapters, parallel DAG campaigns and broader physics
research profiles follow only after their stated release gates pass.

- [0.3–0.6 upgrade program](upgrade_program_0.3_to_0.6.md)
- [Physics Auditor v1](physics_auditor_v1.md)
- [agent backend abstraction](agent_backend_abstraction.md)
- [parallel campaign scheduler](parallel_campaign_scheduler.md)
- [later physics research profiles](physics_research_profiles.md)

The roadmap does not authorize live campaigns, protected-evaluation access, candidate
or historical-evidence changes, or implementation without the listed qualification and
human gates.
