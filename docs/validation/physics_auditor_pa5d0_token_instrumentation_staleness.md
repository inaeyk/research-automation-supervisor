# PA-5D0 token-instrumentation staleness declaration

Status: **stale for execution authority**.

The Codex runtime and model-launch instrumentation changed after the current
PA-5D0 draft artifacts were hashed. Their recorded hashes are historical only
and must not be silently reused as execution authority.

This declaration does not approve or finalize PA-5D0, and no PA-5D benchmark or
GL model session was launched. After token instrumentation qualifies, PA-5D0
authority must be regenerated, re-hashed, and reviewed before PA-5D1.

The instrumentation is observational. It does not change scientific routing,
acceptance, scoring, proof semantics, or qualified scientific conclusions.
