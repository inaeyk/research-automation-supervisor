# Release notes: 0.2.0

Version 0.2.0 is the package-ready release of Research Automation Supervisor. The
version moves from 0.1.0 to 0.2.0 because it adds a supported public command, installed
example resources, distribution metadata, and a user-facing documentation set without
breaking the pre-1.0 workflow schemas.

## Evaluation closure

The supported historical campaign method is now
`run-direct-historical-replay`. It reconstructs task baselines in disposable
workspaces and calls the original functional evaluator on the qualified host after all
model processes stop. The final visible campaign result is 5/5 functional, including
hidden, visible, and changed-path checks, and 0/5 exact historical identity.

Earlier packaged Bubblewrap results of 0/5 and 4/5 are superseded experimental
infrastructure results. The package tools remain installable and tested, but are marked
experimental and non-authoritative. An environment qualification failure is distinct
from candidate failure.

## Install and verify

```bash
python3 -m pip install "research_automation_supervisor-0.2.0-py3-none-any.whl"
research-supervisor --version
research-supervisor doctor
```

For an offline installed-package smoke test, follow the synthetic quick start in the
[README](../../README.md#ten-minute-synthetic-quick-start).

No package was published and no release tag was created as part of release closure.
