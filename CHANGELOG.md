# Changelog

All notable user-facing changes are recorded here. This project follows semantic
versioning while it remains pre-1.0.

## [Unreleased]

### Added

- Physics Auditor PA-1 model-free foundations: strict standalone version-1 physics
  task contracts and untrusted audit reports, closed evidence references, canonical
  serialization/hashes, and an authoritative pure deterministic verdict router.
- Read-only `validate-physics-contract` and `validate-physics-audit` commands. No
  Physics Auditor model execution or workflow integration is available yet.
- Public synthetic physics fixtures plus frozen 0.2.0 compatibility fixtures for
  persisted models, journals, service injection, schemas, hashes, transitions, and
  existing CLI behavior.

### Preserved

- Package version 0.2.0, schema-version-1 ordinary workflow/campaign behavior,
  Codex-specific persisted action proof, existing journal semantic forms, and the
  authoritative historical campaign record remain unchanged.

## [0.2.0] - 2026-07-31

### Added

- Authoritative `run-direct-historical-replay` host-side command with deterministic
  safe summaries, private per-task output, provenance hashes, input immutability
  checks, default disposable-workspace cleanup, and optional retention.
- Synthetic regressions for historical result classification and the mode-`0400`
  hidden-overlay permission case.
- Installed `init-example` resource bundle and non-model end-to-end quick start.
- Public getting-started, campaigns, evaluation, security, troubleshooting,
  development, validation, migration, release-note, and release-checklist docs.

### Changed

- Reconciled the final five-task result as 5/5 functional and 0/5 exact historical
  identity, with direct original historical replay as the authority.
- Marked the packaged Bubblewrap preparation/evaluation/reporting commands as
  experimental, non-authoritative research infrastructure.
- Completed package metadata, classifiers, source-distribution inclusion rules,
  console entry points, and package resource data for a normal wheel/sdist release.
- Rewrote the top-level README around safe public installation and use.

### Preserved

- Historical campaign evidence, stage contracts, audit records, and experimental
  evaluator implementation remain intact. Superseded intermediate scores are labeled,
  not deleted or rewritten.

## [0.1.0] - 2026-07-30

- Initial deterministic contract, Codex adapter, durable substage, retrospective/live
  shadow, visible campaign, immutable candidate, and offline evaluation foundations.
