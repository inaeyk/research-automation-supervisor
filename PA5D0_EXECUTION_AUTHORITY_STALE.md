# PA-5D0 execution authority status

Status: **STALE — NOT EXECUTION AUTHORITY**

The current PA-5D0 preregistration draft predates authoritative Codex runtime token instrumentation. Model-launch artifacts, completion manifests, recovery verification, and campaign ledgers now include machine-derived `turn.completed.usage` receipts and event-log hashes.

Therefore:

- no existing PA-5D0 draft hash may be reused as execution authority;
- this notice does not approve or finalize PA-5D0;
- no PA-5D benchmark or GL model session is authorized by the current draft;
- after token instrumentation qualifies, PA-5D0 authority must be regenerated, rehashed, and independently reviewed before PA-5D1 can begin.
