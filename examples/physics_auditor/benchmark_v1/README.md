# Blind Physics Auditor fixture authority v1

PA-5C1 keeps two physically separate roots:

- `auditor_visible/` contains neutral paired fixture bytes and bounded GL templates.
- `scorer_only/` contains labels, diagnoses, expected routes, categories, severities,
  source-blob authority, and detached review-receipt locators.

Each synthetic `case_NNN` has `variant_001` and `variant_002`. Their title,
contract, filenames, oracle program, and observation schema are byte-identical. Only
`implementation.py` or raw scalar values in `observations.json` may differ. Which
variant is clean is recorded only in the scorer root.

`raw_measurement_oracle.py` accepts only an observation-file path and returns only
normalized scalar measurements. It has no case/task argument, outcome, boolean check,
route, category, severity, or diagnosis.

The GL fixtures are preparation inputs only. PA-5C1 may read their exact source blobs
with `git show` at the frozen commit and verify the resulting visible-byte manifest.
It does not run PA-2, PA-3, a real model, or a GL pilot.

Review receipts are deliberately not generated by
`scripts/build_pa5c1_blind_fixtures.py`. A launch certificate requires a detached,
immutable human-authored receipt whose digest binds the exact paired or GL visible
manifest and whose reviewer identity differs from every fixture-author identity.
